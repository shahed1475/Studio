## 2. The caption ghosting (found and explained)
At each caption change, the previous caption stays drawn behind the new one for about 5 frames (0.17 s): letters overlap, such as "WIREDIEYESNG" or "SCANADIANAIRL".
- Cause: the last word of a caption group was held 0.15 s into the next group. The fix is commit `404ec71` (21 Oct, 12:55 UTC): a group's last word is no longer held into the next one.
- I rebuilt the Skinwalker caption file with today's code and rendered it on a blank clip: **no overlap**. So new videos are fine.
- Affected (rendered before the fix): Knossos (19 Oct), Skinwalker (19 Oct), Thunderbird (20 Oct). Not affected: Voynich and the Korean dragon Short.
- Effect: a brief flicker about every second. Ugly, not harmful. Fixing it in an uploaded video means re-rendering and uploading a new video, because YouTube cannot swap the file.

## 4. Plan
**P0, today (small, safe, tested):**
- No change needed for captions: the code is already fixed. Add a render check that **samples frames at each caption change and fails the video on ghosting** (a frame difference test), so an old defect cannot return unnoticed.
- Add a `picture_repeat` check to the reviewer (warning): more than 20% of the contact-sheet frames show the same picture, or any picture shown more than 3 times.

**P1, this week:**
1. **Picture variety:** raise the minimum number of different pictures per documentary from 6 to about 25 (Pied Piper had 8), and stop using the same facade crop more than twice. Where the archive has too few, draw labelled illustrations of different scenes instead of reusing photos. Cost rises slightly; the repeat is what viewers leave on.
2. **Picture to line match:** reject a stock photo whose subject is not in the line (a Halloween house for "Crying Woman"); prefer a drawing. The reviewer's picture check already warns about "atmospheric" pictures; make it a repair trigger when more than 4 are flagged.
3. **Brand logos and people:** reject photos showing a visible brand logo or a recognisable stranger's face; sensitive photos (a child receiving medical care) never used in an unrelated story.
4. **Shorts source gate:** refuse a Short when its source article is thin (the Thunderbird script said its sources say little).
5. **Style variety:** vary the illustration style per video (sepia storybook, woodcut, watercolour) so the channel does not look like one template, which is also what YouTube's policy text warns about.

**P2, next weeks:**
6. Make the repeated-story warning a repair step.
7. Add a short "what is known, what is legend, what is disputed" segment and on-screen source labels to every documentary.
8. Use Studio's Test & Compare by hand on thumbnails of the best two documentaries, then feed the result into the thumbnail rules.
9. Cap documentary length at about 8 minutes unless the topic needs it (La Llorona is 9:44 and has the weakest picture match).

**How each will be checked:** every P0 and P1 item gets a unit test and a run on the existing videos' contact sheets (a before and after count of repeated pictures per video). I will report the real numbers, not just "tests pass".
